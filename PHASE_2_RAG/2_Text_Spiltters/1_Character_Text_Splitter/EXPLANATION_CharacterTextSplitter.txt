================================================================================
CHARACTER TEXT SPLITTER - DETAILED EXPLANATION
================================================================================

OVERVIEW:
---------
The CharacterTextSplitter is the simplest text splitting mechanism in LangChain. 
It splits text based on a fixed number of characters (chunk_size) with an optional 
overlap between chunks to maintain context.

KEY PARAMETERS:
---------------
1. chunk_size (int): 
   - The maximum number of characters in each chunk
   - Example: chunk_size=100 means each chunk will have ~100 characters max

2. chunk_overlap (int):
   - Number of characters that overlap between consecutive chunks
   - Helps maintain context between chunks
   - Example: chunk_overlap=20 means the last 20 characters of chunk 1 
     will appear in the first 20 characters of chunk 2

3. separator (str):
   - Character or string used to mark chunk boundaries
   - Default is "" (empty string, meaning split by exact character count)
   - Common alternatives: "\n" (newline), " " (space)

HOW IT WORKS - STEP BY STEP:
----------------------------
1. Input: Large text string
2. Count characters from start
3. When character count reaches chunk_size:
   - Create a chunk from start to current position
   - Add overlap characters to beginning of next chunk if overlap > 0
4. Repeat until all text is processed
5. Output: List of text chunks

ADVANTAGES:
-----------
✓ Simple and predictable behavior
✓ Very fast processing
✓ Memory efficient for large texts
✓ Good for non-semantic splitting needs
✓ Consistent chunk sizes

DISADVANTAGES:
--------------
✗ Splits mid-sentence/word (no semantic awareness)
✗ Ignores document structure
✗ Poor for code or structured data
✗ Can break important context
✗ No understanding of content meaning

USE CASES:
----------
• General document chunking for RAG systems
• Preprocessing before semantic splitting
• Simple text files without structure
• When speed is critical over quality
• Fixed-size chunk requirements

--------------------

KEY OBSERVATIONS:
─────────────────
✓ CharacterTextSplitter counts EXACT characters
✓ No regard for word boundaries - can split mid-word
✓ Overlap (if set) repeats end of Chunk N at start of Chunk N+1
✓ Very predictable - same text always produces same chunks
✓ Fast processing - just counts and cuts

CODE EXAMPLE:
=============

from langchain_classic.text_splitter import CharacterTextSplitter

# Initialize the splitter
splitter = CharacterTextSplitter(
    chunk_size=100,        # Max 100 characters per chunk
    chunk_overlap=20,      # 20 character overlap between chunks
    separator=""           # Split exactly by character count
)

# Split the text
chunks = splitter.split_text(text)

# Each chunk in chunks list is a string of ~100 characters


OPTIMIZATION TIPS:
------------------
1. Use chunk_overlap to maintain context (usually 10-20% of chunk_size)
2. Adjust chunk_size based on your model's token limit
3. Combine with document loaders for full pipeline
4. Consider semantic splitting for better results if needed
5. Test with sample data to find optimal chunk_size

WHEN TO USE vs WHEN NOT TO USE:
--------------------------------
USE when:
  ✓ You need simple, fast splitting
  ✓ Processing plain text documents
  ✓ Chunk size is critical requirement
  ✓ Performance is more important than accuracy

DON'T USE when:
  ✗ Processing code or structured data (use Language splitter)
  ✗ Need semantic awareness (use SemanticChunker)
  ✗ Working with markdown or formatted documents
  ✗ Context and meaning matter more than speed
